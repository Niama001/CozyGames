# 🎮 Cozy Games Listicle App

## 🧠 Overview
A simple Express.js web app that displays a list of cozy video games. Users can browse games on the homepage and click each game to view detailed information.

---

## 🚀 Features

### Required Features
- [x] Web server built using Express
- [x] Routes created using Express (`/`, `/games/:slug`)
- [x] Front page displays a list of at least 5 items
- [x] Each item has at least 3 attributes (title, genre, platform, description, image)
- [x] Each item has its own detail page
- [x] 404 page for invalid routes
- [x] Styled using PicoCSS
- [x] Vanilla HTML/CSS/JS (no frontend framework)
