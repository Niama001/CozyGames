# WEB103 Project 1 - Cozy Games 

Submitted by: **Mymuna Murshed**

About this web app: **A simple Express.js web app that displays a list of cozy video games. Users can browse games on the homepage and click each game to view detailed information.**

Time spent: **3** hours
